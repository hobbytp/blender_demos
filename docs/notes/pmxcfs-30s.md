## 时间轴与因果链

| 教学时间 | 动作 | 观察点 |
| --- | --- | --- |
| 0–7.6 秒 | FUSE 写入→quorum 检查→DCDB/DFSM→CPG | 允许进入发送路径不等于写入已经完成 |
| 7.6–15.3 秒 | CPG 向包括 A 在内的各节点交付→memdb→SQLite | 交付后才改内存；本地更新期间读取等待 |
| 15.3–23 秒 | A 的本地处理结果沿调用链返回 | 帧 545：A 已返回，C 的数据库仍在更新；无全节点磁盘 ACK |
| 23–30 秒 | 稳定分区下 C 的新写入被拒绝→本地读取旧配置 | 默认场景保留此前 v2；无 quorum 独立预设保持 v1 |

`pmxcfs-timeline.ts` 从实际字幕词边界派生关键事件。跨节点时间错开是示意，不是实测性能。W1、v1/v2 是教学标签；只跟踪已通过权限入口的单次 FUSE 写，不代表整次 GUI/API 保存。正常路径限定已同步状态，不包含加入、重同步或 I/O 失败。
