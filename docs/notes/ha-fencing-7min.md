## 章节与实际制作

| 播放时间 | 内容 | 新增的可观察过程 |
| --- | --- | --- |
| 00:00–00:30 | 失联却仍在服务 | 业务请求与磁盘 I/O 继续，目标实例不启动 |
| 00:30–01:05 | 回到正常，展开角色 | 按旁白揭示 CRM、LRM、各节点 pmxcfs；区分两类锁 |
| 01:05–01:40 | 正常续期与状态协作 | 续锁请求/成功、本地续期、设备喂狗；切换到管理状态和执行结果路径 |
| 01:40–02:15 | 持续分区 | 只中断 C 的集群通信；多数侧两票、少数侧一票 |
| 02:15–02:50 | 失锁但 VM 未停 | 本地配置层约束、LRM 失锁、续期中止与仍在运行的 VM 分开呈现 |
| 02:50–03:30 | 两层 watchdog | 客户端超期、设备停喂、主机复位与旧实例 I/O 停止 |
| 03:30–04:10 | 回看多数侧的并行等待 | C 的客观状态与 B 的 unknown/锁操作依据分开，保留双轨事件条 |
| 04:10–04:45 | fencing 判定 | 旧节点锁获取成功的返回脉冲来自 B 的配置层，随后进入 recovery |
| 04:45–05:30 | 恢复配置归属并启动 | 选择 B、移动配置归属、发布期望、LRM 建立保护、本地资源 agent/QEMU 启动、回写结果 |
| 05:30–06:05 | VM 与应用状态 | 三栏区分 HA 期望、QEMU 运行及独立业务探测；磁盘原位、旧运行内存未传送 |
| 06:05–06:35 | 判断题 | 旧节点锁尚未取得的假设题；提问配音结束后留约 6.94 秒，再给答案 |
| 06:35–07:00 | 回顾与下一集 | 保留两侧因果链，连接下一集热迁移 |

13 段真实配音共 325.728 秒，均在时间槽内；剩余时间用于观察状态、章节衔接和判断题。实际可播放文案位于 `src/ha-lesson-narration.json`，是首集长稿的口语精简版。字幕来自 Edge TTS WordBoundary，未按字数均分。

关键状态使用 `haCue()` 按具体旁白短句寻找实际词边界，再转换成帧。缺失短句会报错；修改文案时要同步事件引用并重新检查因果顺序。这些是编辑时间点，不是 PVE 超时参数。

## 专业审查与边界

- 分布式协议：不画 C 发往 B 的关机 ACK；导演看到的主机复位不替代多数侧获取旧节点锁的结果。
- 实现：正常路径区分续锁与 HA 管理状态读写；CRM/LRM 通过配置层状态协作，启动经目标节点本地资源 agent 和 QEMU 管理接口。
- 操作系统：区分 LRM 客户端续期与 mux 设备喂狗；保留 B 的 CRM watchdog 保护，B 的空闲 LRM 不无条件标为持锁。目标 LRM 在本例启动前建立保护。
- 存储：配置归属标签移动，共享 NFS 磁盘对象不动；只在相应实例运行时显示其磁盘 I/O。
- 教学与动效：沿用样片颜色、节点位置和组件；分段揭示并聚焦相关路径。第一次分区是问题预览，00:30 明确回到故障前；03:30 明确回看同一故障的另一侧。
- 可观测性：应用就绪来自独立业务探测示意，不能当成 HA 内置应用健康检查或真实业务恢复证据。

官方 HA 章节本轮重新读取成功，本地 `pve-ha-manager` 仍为 `c73364c19d5317e6df5bb1c1b727d080a5e897ef`。这是限定前提下的机制动画，尚未固定一套已安装的软件包组合，也未做实机分区、watchdog 或应用恢复实验。逐帧状态检查不构成任意部署下的协议证明；首次观众理解度仍需观看反馈。
