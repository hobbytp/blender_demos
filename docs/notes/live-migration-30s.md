# PVE 02：热迁移 30 秒机制样片 v1

2026-09-13。已完成中文旁白、逐词字幕、交互对照与 MP4；完整 7 分钟课件尚未制作。[完整讲稿、分镜与固定源码](pve-ep02-live-migration.md)。

## 观看与复现

- `npm.cmd run dev`，打开 `http://127.0.0.1:5173/?sample=migration`。
- `npm.cmd run render:migration` → `out/live-migration-30s-v1.mp4`。
- `npm.cmd run voice:migration` 重生成本样片全部四段配音；不支持指定单段。修改时先保护旧音频并遵循 explain-tech-video 的局部修订流程。
- 页面可切换“成功迁移”和“切换前失败（无旁白）”；点击章节会恢复成功场景并暂停。MP4 只导出成功场景。

## 样片节奏

| 时间 | 画面事件 | 可观察状态 |
| --- | --- | --- |
| 0–7.6 秒 | incoming 准备、第一轮页组传输 | C 执行，B 只接收；抵达后目标更新 |
| 7.6–15.3 秒 | P2 / P5 变脏并重传，P2 再次写入 | 同一页 v1 → v2 → v3；目标保留尚未追上的旧值 |
| 15.3–23 秒 | 暂停 C、最终 RAM 与 vCPU / 设备同步 | 两端来宾暂不执行；QEMU 随后 completed |
| 23–30 秒 | 配置归属 C → B、resume、源进程清理 | B 恢复执行及磁盘 I/O，NFS 不移动 |

四段 TTS 实际时长为 6.096、7.032、6.600、6.144 秒，总计 25.872 秒，全部落在各自时间槽内。使用 Edge TTS Yunxi、+8%，字幕由 WordBoundary 生成。`migrationBeats` 从实际字幕短句定位关键事件；更改文案或重配音后须重跑因果检查。

这不是协议模拟器。八个方块是页组，版本号是教学标签；暂停和传输按教学需要放大。RAM 与设备分别呈现便于理解，不声称内部序列化总是严格先 RAM 后全部设备。失败分支仅限预拷贝期间、源端未暂停且源端和控制路径健康；不能推定其他阶段也可无损回滚。
